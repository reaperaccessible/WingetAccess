Changelog

WingetAccess. The most recent versions are at the top.

Version 1.06

  • New: the manual opens with F1 and this changelog with Ctrl+F1, in the interface language. They are built into the WingetAccess.exe file: nothing more to keep next to it, and they follow every update.
  • The help key becomes Ctrl+Shift+H, as in every product of the family (Ctrl+H before). It now opens a list of the shortcuts to browse with the arrows; Escape closes it and takes you back where you were.
  • Accessibility: no more silent list edges. Up on the first row announces "First," followed by the row; Down on the last row announces "Last,".

Version 1.05

  • At the end of the startup check, WingetAccess announces "7 updates available" (or "1 update available", "No updates available") instead of "7 updates".

Version 1.04

  • At startup, WingetAccess announces "Please wait while WingetAccess checks for available updates."

Version 1.03

  • New: the progress is announced during an install or an update: "Downloading 35%", in 5% steps, then "Installing…" when the installer starts. An uninstall announces "Uninstalling…".
  • Fix: the log now shows everything Winget says during an install, an update or an uninstall. These lines were missing.

Version 1.02

  • New: WingetAccess speaks English and French. The interface follows the Windows language at startup.
  • Fix: on a French Windows, a program's description (Tab from a list) is complete again: version, publisher, author, description and license.
  • Descriptions written on several lines are now read in full.

Version 1.01

  • New: WingetAccess prepares Winget on its own. On a new computer or when Winget was never used, it activates, repairs or installs it as needed, and accepts the source agreements. No more typing Y in a console.
  • When a newer Winget exists, it is installed first, automatically.
  • "Update all" processes programs one at a time and announces each one, for example "Update 3 of 8: Firefox…", then gives the summary.
  • New: WingetAccess updates itself at startup (Help menu: "Check for a WingetAccess update").
  • App Installer, which contains Winget, can no longer be uninstalled by mistake from WingetAccess.

Version 1.00

  • First version: three tabs (Installed, Updates, Search), opened with Ctrl+1, Ctrl+2 and Ctrl+3, whose name is announced.
  • Enter updates or installs the chosen program, Ctrl+Shift+U updates everything, Delete uninstalls, without ever typing a command.
  • A Description box in every tab, read with Tab from the list.
  • The Installed tab only shows the programs Winget can manage.
  • When two versions of the same program are installed, the version of the chosen row is the one uninstalled.
  • Portable program: a single file, nothing to install.
