WingetAccess — Manual

WingetAccess lets you install, update and uninstall your Windows software without ever typing a command, with your screen reader (NVDA, JAWS or Narrator). It relies on Winget, the software manager built into Windows: you no longer need to copy a program's name to type "winget install" or "winget upgrade" by hand.

WingetAccess is a portable program: a single file, WingetAccess.exe, that you put wherever you like. There is nothing to install, and it updates itself.

At startup

When it opens, you hear "Please wait while WingetAccess checks for available updates." WingetAccess then checks Winget, loads your installed programs and the available updates. When it is done, it announces the number found, for example "7 updates available".

WingetAccess prepares Winget on its own. On a new computer, or when Winget has never been used, it activates, repairs or installs it as needed, and accepts the terms of use of the software sources for you. You never have to type "Y" in a console. If a newer Winget exists, it installs it first, before anything else.

If Winget really cannot be prepared (without an Internet connection, for example), a dialog box explains it. Check the connection, then press F5 to try again.

The window

The window has three tabs:

  • Installed: the programs on your computer that Winget can manage, with their name, ID, version and, when there is one, the available version. Programs that Winget sees but cannot manage are not listed.
  • Updates: only the programs that have a newer version.
  • Search: a field to look for a program, the "Start search" button and the list of results.

In each tab, a Description box follows the list. At the bottom of the window, the Log keeps the details of everything that happened.

Moving around

  • Ctrl+1, Ctrl+2 and Ctrl+3 open the Installed, Updates and Search tabs. The tab name is announced, then the selected row. For Search, the cursor goes straight to the field.
  • In a list, the Up and Down arrows move from one program to the next. The edge of a list is never silent: Up on the first row announces "First," followed by the row, and Down on the last row announces "Last,".
  • Tab and Shift+Tab move from one area to the next: list, description, log.

Installing a program

  • Press Ctrl+3, type a word ("audacity", "7zip"…), then Enter.
  • The number of results is announced and the cursor moves to the list.
  • Choose a result with the arrows, then press Enter (or Ctrl+I). The install runs without any window, accepting the licenses for you.

Updating your programs

  • In the Updates tab (Ctrl+2), choose a program then press Enter (or Ctrl+U).
  • Ctrl+Shift+U updates everything, after confirmation. Programs are processed one at a time and each one is announced, for example "Update 3 of 8: Firefox…". At the end, you hear the summary: the number of successes and failures.
  • In the Installed tab, Enter also tries to update the chosen program. If there is nothing to update, Winget simply says so.

After each operation, the Installed and Updates tabs refresh on their own.

Uninstalling a program

  • In the Installed or Updates tab, choose the program then press Delete.
  • Answer "Yes" to the question "Uninstall …?".
  • When two versions of the same program are installed under the same ID, the version of the chosen row is the one uninstalled.
  • App Installer, which contains Winget, cannot be uninstalled from WingetAccess: without it, WingetAccess could no longer do anything.

A program's description

From a list, press Tab: the Description box reads the details of the selected program: its version, publisher, author, description, home page and license. It loads in the background when you stop on a row. If you get there before it has loaded, you hear "Loading description…", then the details are read as soon as they are ready. Descriptions come from the programs' publishers.

What you hear during an operation

  • At the start: "Installing …", "Updating …" or "Uninstalling …".
  • During the download: the progress, in 5% steps, for example "Downloading 35%". On a very fast connection, some steps may be skipped.
  • When the installer starts: "Installing…" (or "Uninstalling…"). This step has no percentage, because silent installers do not report one.
  • At the end: "Done", or "Failed" followed by a code. The details are in the log.

One operation runs at a time. If you ask for another while one is running, you hear "Busy, operation in progress".

The log

The Log box, at the bottom of the window, is read-only. It keeps everything Winget said during the session: install lines, errors, Winget preparation. When an operation fails, that is where the exact reason is.

Windows permissions

WingetAccess starts without administrator rights. When a program needs them to install, Windows itself shows the permission request (UAC), at the right moment. Answer "Yes" to continue.

WingetAccess updates

At every start, WingetAccess checks whether a newer version of itself exists. If so, it downloads it, checks that it is intact, takes its place and restarts on its own. You then hear "WingetAccess updated, version …". It always waits for the end of a running operation: an install is never interrupted.

To check on demand: Help menu, "Check for a WingetAccess update".

Language

WingetAccess follows the Windows language at startup: any French Windows, including Canadian French, gives French; every other one gives English. The texts that come from Winget (columns, descriptions, log lines) are written by Winget in the Windows language.

To force a language, start WingetAccess.exe --lang=en or WingetAccess.exe --lang=fr, for example from a shortcut.

Keyboard shortcuts

Ctrl+Shift+H opens the list of all the shortcuts, to browse with the Up and Down arrows; Escape closes it and takes you back where you were. Here it is:

  • Ctrl+1: Installed tab
  • Ctrl+2: Updates tab
  • Ctrl+3: Search tab (the cursor goes to the field)
  • Enter in a list: update (Installed, Updates) or install (Search)
  • Tab from a list: description of the selected program
  • Ctrl+U: update the selection
  • Ctrl+Shift+U: update all
  • Ctrl+I: install the selection
  • Delete: uninstall the selection (with confirmation)
  • Ctrl+Shift+C: copy the program ID
  • F5: refresh the current tab (or prepare Winget again)
  • F1: manual
  • Ctrl+F1: changelog
  • Ctrl+Shift+H: this list of shortcuts
  • Alt+F4: exit

Two more shortcut letters: Alt+S goes to the search field (in the Search tab) and Alt+L goes to the log.

Troubleshooting

  • An operation fails: read the last lines of the log, which give Winget's reason.
  • "winget not found": check the Internet connection then press F5. You can also install "App Installer" from the Microsoft Store, then press F5.
  • "Busy, operation in progress": wait for the running operation to end, announced by "Done" or "Failed".
  • A program is not in Installed: Winget cannot manage it (it is not in its sources). Look for it in the Search tab.
